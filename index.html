2. ¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite registrar cambios y mantener el historial de un proyecto.

3. ¿Qué es GitHub?

GitHub es una plataforma que permite alojar repositorios Git y colaborar en proyectos.

4. Comandos básicos de Git

Durante esta práctica aprendí a utilizar:

  • git init: inicializar repositorios.
  • git status: consultar cambios.
  • git add: preparar archivos.
  • git commit: registrar versiones.
  • git log: consultar el historial.
  • git branch: administrar ramas.
