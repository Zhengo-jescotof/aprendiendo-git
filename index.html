2. ¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite registrar cambios y mantener el historial de un proyecto.

3. ¿Qué es GitHub?

GitHub es una plataforma que permite alojar repositorios Git y colaborar en proyectos.
