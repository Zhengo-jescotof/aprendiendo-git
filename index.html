2. ¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite registrar cambios y mantener el historial de un proyecto.

3. ¿Qué es GitHub?

GitHub es una plataforma que permite alojar repositorios Git y colaborar en proyectos.

3.1. Manejo de ramas en Git

Las ramas permiten desarrollar nuevas funcionalidades sin modificar directamente la rama principal del proyecto.

Comandos para trabajar con ramas

  • git branch: consultar las ramas existentes.
  • git switch -c feature/seccion-ramas: crear una rama y cambiar a ella.
  • git switch main: regresar a la rama principal.
  • git merge feature/seccion-ramas: integrar los cambios de la rama de trabajo.
  • git log --oneline --graph --all: visualizar el historial de las ramas.

En esta práctica utilizo una rama feature para incorporar contenido HTML y CSS mediante dos commits, antes de fusionarla con main.

4. Comandos básicos de Git

Durante esta práctica aprendí a utilizar:

  • git init: inicializar repositorios.
  • git status: consultar cambios.
  • git add: preparar archivos.
  • git commi0t: registrar versiones.
  • git log: consultar el historial.
  • git branch: administrar ramas.
